# **App Name**: FileFixer AI

## Core Features:

- File Upload: Allow users to upload their file to the chatbot.
- XML Definition Upload: Allow users to upload the XML file defining file content rules.
- Issue Detection: Analyze the uploaded file against the provided XML definition to identify issues, including format errors in emails, SSNs, and names.
- Suggestion Generation: Use the AI model to provide suggestions on how to fix identified issues, incorporating file content definition as a tool.
- Fix suggestion Display: Display the issue along with its fix.
- Chatbot Interface: Provide a conversational chatbot interface for interaction.
- API Integration: Connect with the user's FastAPI endpoint, sending the prompt and necessary documents, then showing AI results to the user.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to evoke trust and precision.
- Background color: Light blue-gray (#ECEFF1) for a clean and professional feel.
- Accent color: Teal (#009688) for highlighting issues and suggestions.
- Body font: 'Inter', sans-serif, for a modern and readable text.
- Headline font: 'Space Grotesk', sans-serif, for prominent, technical headings.
- Use clear and informative icons to represent file types, errors, and suggestions.
- Subtle transitions and animations to enhance user experience.
